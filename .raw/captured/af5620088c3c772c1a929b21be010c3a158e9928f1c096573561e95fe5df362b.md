# Brain v2 Mission Control technical contract

## Canonical runtime

The shared Markdown vault is the canonical learning source. Mission Control reads the governed Brain v2 graph from `/api/brain/v2/graph`; it does not turn visual proximity, lexical suggestions, or decorative motion into knowledge.

## Evidence and provenance

Governed graph edges require explicit wiki links, source-backed claims, completed transaction artifacts, recorded handoffs, retrieval records, task ownership, or explicit skill-use records. Recommended skills remain unverified until an agent records invoked, verified, failed, or skipped status. Task and retrieval provenance stores hashes and identifiers, not task text, query text, credentials, or secret values.

## Writes and compatibility

Inbox capture is create-only. Canonical capture and promotion require reviewed transactions and exact approval hashes. The legacy `/api/brain` read remains compatibility-only until the new Mission Control consumes the governed v2 graph. Obsidian is optional because storage, links, search, transactions, and visualization use ordinary local Markdown and dashboard APIs.
